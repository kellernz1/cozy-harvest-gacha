# 🌾 Cozy Harvest Gacha

Cozy Harvest Gacha is a small browser farming game built with Vite, React, TypeScript, and Tailwind CSS.

## ✨ Features

- Idle farm income from planted fruit seeds.
- Seed packs with rarity rates.
- Daily fruit market bonus that changes sell/income value.
- Daily goals, achievements, and fruit collection tracking.
- Plot unlocks, watering, fertilizer, reforging, and skill upgrades.
- Local save in the browser.

## 📜 Scripts

- `npm run dev` starts the local dev server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm run test` runs Vitest.

## 🚀 GitHub Pages

The project is configured to deploy from GitHub Actions.

Push to `main`, then enable GitHub Pages with **Source: GitHub Actions** in the repository settings.
